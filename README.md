E-Commerce Website

Project Description

I developed a responsive E-Commerce Website where users can explore products and view product details. The website provides a simple and user-friendly interface for online shopping.

Features

- Home page with an attractive design
- Product listing and product details
- Easy navigation between pages
- Responsive and user-friendly interface
- Interactive elements for a better user experience

Technologies Used

- HTML
- CSS
- JavaScript

Purpose

The main purpose of this project is to create a simple online shopping website and improve my web development skills.

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open the "index.html" file in your browser.
